# 赛题要求（原文要点摘录）

来源：<https://challenge.xfyun.cn/topic/info?type=Wheat-SOD-train> · 「三、评审规则」「四、作品提交要求」
摘录日期：2026-11-22

## 1. 数据说明

- 本次比赛所用数据为**田间实拍小麦图像**，覆盖不同拍摄角度、光照条件和麦穗密度场景，具有真实复杂的农业背景。
- 数据集包含训练集、验证集和测试集，**图像分辨率不统一**。
- 目标为图像中的麦穗，标注格式为 YOLO：

  ```
  <class_id> <x_center> <y_center> <width> <height>
  ```

  - `class_id`：类别编号（整数，从 0 开始）
  - `x_center, y_center`：边界框中心的**归一化坐标**（相对图像宽高的比例，范围 [0,1]）
  - `width, height`：边界框的**归一化宽高**（范围 [0,1]）
  - 仅包含一个类别：**麦穗（wheat_ear）**
- 训练集和验证集附带完整标注，**测试集仅提供图像**用于模型评估与排名。

## 2. 评估指标

- 依据提交的检测结果文件，采用 **mAP@0.5** 作为评估指标进行打分与排序。

## 3. 评测及排行

1. 本赛题均提供下载数据，选手**在本地进行算法调试**，在比赛页面提交结果。
2. **测试集仅可用于输出最终的推理结果，不可以任何形式参与训练过程。**
3. 排行按照得分从高到低排序，排行榜将选择**团队的历史最优成绩**进行排名。

## 4. 作品提交要求

1. **文件格式**：提交 `submit.zip`，内含 `submit` 文件夹，文件夹内为与**测试集图片同名的 txt** 文件，
   txt 编码为 **UTF-8**。每行表示一个检测到的目标，格式为：

   ```
   <class_id> <x_center> <y_center> <width> <height> <confidence>
   ```

   - `confidence` 为检测置信度（0~1）
   - 其余字段与标注格式相同（归一化坐标），**分隔符为空格**
2. **文件大小**：无要求
3. **提交次数限制**：每支队伍**每天最多 3 次**

## 5. 对本项目的约束（落地检查清单）

| 要求 | 本项目如何满足 |
|---|---|
| zip 内 `submit/` 目录 | `make_submission.py` 用 `arcname="submit/<name>.txt"` |
| 与测试图同名 | 用 `p.stem` 命名（`0001.png` → `0001.txt`），并校验 100/100 齐全 |
| UTF-8 | `open(..., encoding="utf-8")`；校验拒绝 BOM |
| 空格分隔 6 字段 | 校验每行字段数 = 6、可解析 |
| 归一化坐标 | `boxes.xywhn`（ultralytics 已归一化）+ 校验范围 |
| class_id 从 0 | 单类，恒为 0；校验非 0 报错 |
| confidence ∈ (0,1) | 取 `boxes.conf`；校验范围 |
| 换行符 | 强制 LF（`newline="\n"`），并在打包时把 CRLF 归一化 |
| 每日 3 次提交 | 本地用 val 选型，避免浪费提交次数 |
| 测试集不参与训练 | 只用 `images/test` 推理，训练/调参全在 train+val 上 |
