# 环境说明（已完成，可直接训练）

日期：2026-11-22　机器：RTX 4090D 24GB / i9-14900KF / Windows / **Python 3.12.14**

## 1. 为什么不用 pip / venv

本机 pip **必然失败**（实测 2026-11-22）：

```
ERROR: Could not install packages due to an OSError: [Errno 13] Permission denied:
'C:\Users\...\Temp\dsh-xxxx\pip-unpack-xxxx\six-1.17.0-py2.py3-none-any.whl'
```

原因：DSH 沙箱不允许在临时目录里删除/重命名已解包的文件，pip 的原子重命名这一步被拦。
（`python -m venv` 同样依赖 ensurepip → 同样失败。）

**方案**：使用预解包好的包树 `pkgs\`（cp312 wheel，torch 2.6.0+cu124 全套），通过 `PYTHONPATH` 挂载。
后续需要新包时用替代安装器：

```powershell
. .\env.ps1
& $env:WHEAT_PY scripts\add_pkg.py onnx onnxruntime      # 查 PyPI -> 下 wheel -> 解包进 pkgs
```

## 4. 用法

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force   # 本机脚本未签名，必须先放开
cd E:\小麦
. .\env.ps1        # 设置 PYTHONPATH / YOLO_CONFIG_DIR / PYTHONUTF8，并导出 $env:WHEAT_PY
```

`env.ps1` 做了什么：

| 变量 | 值 | 作用 |
|---|---|---|
| `PYTHONPATH` | `E:\小麦\pkgs` | 挂载 torch/ultralytics |
| `YOLO_CONFIG_DIR` | `E:\小麦\_cfg\ultralytics` | 避免 ultralytics 写用户主目录 |
| `MPLCONFIGDIR` | `E:\小麦\_cfg\mpl` | 同上（matplotlib 缓存） |
| `WHEAT_PY` | DSH 自带 3.12 解释器 | 训练/推理统一用它 |

## 5. 三个必须知道的沙箱限制

1. **不能 `pip install`** → 用 `scripts\add_pkg.py`。
2. **不能多进程**：沙箱禁止命名管道，`multiprocessing.Pool`（含 `ThreadPool`）报 `WinError 5`。
   已用 `sandbox_compat.py` 把池替换成串行实现，并把 `workers` 默认值设为 `0`。
   `train.py` 里 `import sandbox_compat` 必须写在 `from ultralytics import YOLO` **之前**。
3. **路径含中文**：`.ps1` 文件不要硬写 `E:\小麦`——无 BOM 的 UTF-8 会被 Windows PowerShell
   按 ANSI 读出乱码（实测会把 `小麦` 读成 `灏忛害`）。一律用 `$PSScriptRoot` 拼。
   Python 侧因为 `PYTHONUTF8=1` 不受影响。

## 6. 解释器选择

- 用的是 DSH 自带 3.12.14：
  `C:\Users\Administrator\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe`
- 系统里还有 `D:\python.exe`（3.13）和 `Python38`——**都不能**加载 `pkgs\` 里的 cp312 扩展（ABI 不匹配），别混用。
