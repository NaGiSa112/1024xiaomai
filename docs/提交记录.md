## 填写说明

- **线上 mAP@0.5**：直接抄排行榜分数（保留 5 位小数）
- **本地参考**：对应的干净口径指标（折外 OOF 或官方 val），用来算"线上-本地偏移"
- **结论**：一句话说明这次提交验证了什么（例如"偏移标定：本地 0.94 → 线上 0.925，差 1.5 点"）

## 提交纪律

1. 只用**本地复算过**的包提，不空提；
2. 一次只改一个变量（尺度组合 / 融合方式 / box_scale / 模型成员）；
3. 每次提交后在 `docs/实验记录.md` 里补一行对应的训练 run；
4. 不把测试集标注用于训练/调参（`docs/重叠检查.md` 有筛查证据）。
