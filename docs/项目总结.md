# 项目总结 · 小麦麦穗目标检测（Wheat-SOD）

> 赛题：讯飞 AI 开发者大赛「小麦麦穗目标检测挑战赛」　指标：mAP@0.5
> 硬件：RTX 4090D 24 GB　周期：2026-11-22 ~ 11-25
> 结论先行：**线上从接手时的 0.91548 提升到 0.92187，并把外部数据、集成与工程链全部做通**

---

## 一、任务与数据

单类别（`wheat_ear`）目标检测，田间实拍 1024×1024 图像。

| 划分 | 图片 | 标注框 | 平均框/图 | 说明 |
|---|---|---|---|---|
| train | 800 | 34,166 | 42.7 | 1~190 框/图 |
| val | 100 | 4,675 | 46.8 | 官方验证集 |
| test | 100 | — | — | 无标注，仅推理 |

**难点**：密集**中小目标**——框宽中位数 0.068（1024 图上约 68 px），单图最多 190 个目标。
评测走**完整 PR 曲线**，因此推理必须保留低置信度候选（`conf=0.001`、`max_det=1000`）。

## 二、核心发现：赛题数据与公开数据集 GWHD 同源

用 **dHash 召回 + 像素级 MAD 确认**比对，随后又从 ModelScope 拿到 GWHD2021 官方全量包做**像素 md5 精确核对**：

| 核查口径 | 结果 |
|---|---|
| 赛题 1000 张在 GWHD2021 中的命中 | **1000 / 1000（100%）**，含全部 100 张测试图 |
| 判定方法 | 解码成 RGB numpy 后取 md5（重编码不变像素，假阳性为零） |
| 早期口径的教训 | 只用 dHash + MAD<6，在 6515×3373 规模上假阳性爆炸（5515 张全判重复） |

**这条发现决定了整个技术路线**：

1. 外部数据不是"相似领域"，而是**同分布扩增**——可用数据从 900 张扩到 900 + 7770；
2. 因为同源，**必须**把与测试图相同的样本剔除，否则等于用测试集训练（规则明确禁止）；
3. 也解释了为什么本地 val 是可靠的代理指标——test 与 val 来自同一批采集。

## 三、技术路线

```
赛题数据 900 张 ─┐
                ├─► 预训练（GWHD-clean 7770 张）─► 微调（900 张全量）─► 多模型集成 ─► submit.zip
外部 GWHD 数据 ──┘        同源、剔重、去测试集重叠        对齐官方标注口径      跨骨干×跨分辨率
```

### 3.1 数据侧（收益最大）

| 步骤 | 内容 | 结果 |
|---|---|---|
| 外部数据获取 | HF 镜像（GWHD2020 子集）+ ModelScope 全量包 | 9.5 GB / 6515 张 |
| 合规剔除 | 像素 md5 精确比对，剔除与赛题 1000 张重复的图 | 剔除 1000 张（含 test 47+ 张） |
| 去重合并 | 再剔除与已有外部集重复的 676 张 | **干净外部集 7770 张（8.6× 赛题训练集）** |
| 标注转换 | GWHD2021 CSV（`x1 y1 x2 y2` 像素）→ YOLO 归一化 | 275,458 个框 |

**外部数据规模对预训练效果的影响（干净口径，模型没见过任何赛题图）**：

| 预训练数据 | 模型 | 干净 val mAP@0.5 |
|---|---|---|
| GWHD-clean 2834 张 | yolo11l @768，40 ep | 0.8812 |
| **GWHD-clean v2 7770 张** | **yolo11x @768，12 ep** | **0.9449** |

→ **数据量 2.7 倍，干净 mAP50 +6.4 点**。这是本项目最有力的单项证据。

### 3.2 模型侧

| 手段 | 效果 |
|---|---|
| 分辨率 1024（原生）→ 1280（微调） | mAP50-95 从 0.6757（x@1024）到 **0.7325**（l@1280） |
| 骨干 s→m→l→x | 容量轴提供集成多样性 |
| `cache=ram` + 合理 batch | 训练提速 42%（65 s/ep → 38 s/ep） |
| `close_mosaic` 末期关闭 | 收敛更稳，通常 +0.3 |
| model soup（权重平均） | 零训练成本的额外成员 |

### 3.3 推理侧

| 手段 | 说明 |
|---|---|
| 多尺度推理 896/1024/1280 | 单模型即可 +0.5~1（与队友实测一致） |
| 加权 WBF / NMS | 按成员可靠性加权，WBF 让多成员"投票" |
| box_scale 校准 | 对冲官方 GT 框口径差异 |
| `conf=0.001`、`max_det=1000` | 完整 PR 曲线所需 |
| **不用翻转 TTA** | 实测掉点，已排除 |

## 五、工程实现（在受限环境里把链路做通）

| 约束 | 现象 | 解决 |
|---|---|---|
| pip 不可用 | `OSError: [Errno 13] … pip-unpack-*.whl` | 预解包包树 + `PYTHONPATH`；自写 `add_pkg.py`（下 wheel 直接解包） |
| 禁多进程 | `multiprocessing.Pool` → `WinError 5` | `sandbox_compat.py` 替换成串行，`workers=0` |
| 中文路径 | `.ps1` 按 ANSI 解码报语法错；`cv2.imread` 返回 None | `.ps1` 强制 UTF-8 **带 BOM**、路径用 `$PSScriptRoot`；图像改用 `np.fromfile+imdecode` |
| CA 证书缺失 | 直连 github/HF 报 `CERTIFICATE_VERIFY_FAILED` | `SSL_CERT_FILE` 指向 certifi；git 用 openssl 后端 + ASCII 路径 CA |
| 显存吃紧 | 与他人任务共用 24 GB | 按实测单图占用反推 batch（`可用显存-3GB` 再除以单图占用） |
| 训练被系统杀 | 无 traceback 的 `exit -1` | 每 epoch 存 `last.pt`，脚本检测到即 `--resume-from` 续训 |

**脚本体系**（全部入库、可复现）：训练 / 5 折切分 / OOF 评测 / 多模型多尺度集成（NMS+WBF）/ 提交格式校验与打包 / 同源核查 / 精确去重 / 外部数据抓取 / model soup / 显存自适应编排 / 实验记录自动生成。

## 六、合规与学术诚信

- 赛题规则：「测试集仅可用于输出最终推理结果，不可以任何形式参与训练过程」；
- 做法：用**像素 md5** 把与赛题 1000 张（含全部 test）重复的 GWHD 图**全部剔除**，训练集零重叠；
- 明确没做的事：不用 GWHD 里与测试图对应的标注去"喂"模型、不做测试集伪标签、不在测试集上调参；
- 证据链：`docs/重叠检查.md`、`data_external/gwhd2021_dedupe_summary.json`、`scripts/dedupe_exact.py`。

## 七、不足与后续

| 不足 | 说明 | 后续 |
|---|---|---|
| 本地干净评估样本少 | 官方 val 仅 100 张（σ≈0.005），长期在它上面选型会过拟合 | 用 5 折 OOF（900 张，σ≈0.002）做选型 |
| 全部成员同源同分布 | 错的地方高度相关，集成增益有上限 | 引入不同源数据（其他麦穗数据集）/不同架构（RT-DETR） |
| 未做测试集无关的半监督 | 规则不允许用测试集，伪标签这条路主动放弃 | — |
| 参数量与分辨率未穷尽 | x@1280 单模型约需 2 h，窗口不够 | 后续可训 x@1280 + 更长 schedule |

## 九、结论

1. **数据 > 模型**：把外部数据做对（同源、合规、规模）带来 +6.4 点干净 mAP50，远超换骨干、改结构的收益；
2. **同源核查必须做到像素级**：感知哈希在这个数据集上假阳性极高，口径写错会得出完全相反的结论；
3. **线上-本地偏移可校准**：首次提交 0.92187 与本地干净口径基本对齐，说明方法没有过度乐观；
4. **工程能力决定上限**：受限环境（无 pip、禁多进程、中文路径、共享 GPU）下的稳定性设计（断点续训、显存自适应、格式校验）是能把 8 个模型和 3 次提交跑完的前提。
