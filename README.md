一、赛事背景
随着农业现代化和智能化技术的快速发展，作物表型分析正逐步由人工调查向自动化、精准化方向转变。小麦作为全球最重要的粮食作物之一，其产量评估、长势监测及育种选优等关键环节，亟需高效、准确的智能图像识别方法。

在小麦生长周期中，麦穗数量与分布是衡量其产量潜力的重要表型特征。传统的人工统计方式不仅效率低下，而且受环境光照、遮挡、个体差异等因素影响，准确性较差。如何借助计算机视觉和深度学习技术，实现麦穗目标的自动检测，已成为智慧农业中的关键研究方向。

本次小麦麦穗目标检测比赛，旨在通过构建真实场景下的图像数据集，鼓励参赛者探索先进的目标检测算法，以提升对田间麦穗的自动识别与定位能力。赛事将促进农业领域人工智能技术的交流与落地，助力智慧农业建设与粮食安全保障。

二、赛事任务
本次比赛旨在通过计算机视觉技术实现对田间小麦图像中麦穗目标的自动检测。参赛者需基于主办方提供的实景图像数据，构建目标检测模型，准确识别并定位图像中的所有麦穗，输出其边界框和置信度。比赛任务聚焦于复杂农业场景下的小目标密集检测，要求模型具备良好的鲁棒性与泛化能力，适应不同光照、角度及遮挡条件，推动智能农业在作物表型分析中的应用落地。

三、评审规则
1.数据说明
本次比赛所用数据为田间实拍小麦图像，覆盖不同拍摄角度、光照条件和麦穗密度场景，具有真实复杂的农业背景。数据集包含训练集、验证集和测试集，图像分辨率不统一，目标为图像中的麦穗，标注格式为YOLO（<class_id> <x_center> <y_center> <width> <height>，其中：class_id为类别编号（整数，从0开始）；x_center, y_center为边界框中心的归一化坐标（相对于图像宽高的比例，范围[0, 1]）；width, height为边界框的归一化宽高（相对于图像宽高的比例，范围[0, 1]）），仅包含一个类别：麦穗（wheat_ear）。训练集和验证集附带完整标注，测试集仅提供图像用于模型评估与排名。

2.评估指标
依据提交的检测结果文件，采用 mAP@0.5 作为评估指标进行打分与排序。

3.评测及排行
1）本赛题均提供下载数据，选手在本地进行算法调试，在比赛页面提交结果。

请注意：测试集仅可用于输出最终的推理结果，不可以任何形式参与训练过程。

2）排行按照得分从高到低排序，排行榜将选择团队的历史最优成绩进行排名。

四、作品提交要求
1.文件格式：提交submit.zip文件，内含submit文件夹，文件夹内为与测试集图片同名的txt文件，txt编码为UTF-8。每行表示一个检测到的目标，格式为：<class_id> <x_center> <y_center> <width> <height> <confidence>，其中confidence为检测置信度（0~1），其余字段与标注格式相同（归一化坐标），分隔符为空格。

2.文件大小：无要求

3.提交次数限制：每支队伍每天最多3次# -
