# 冲刺 96 分 · 三轮计划

> 2026-11-24 12:00 起　目标：线上 mAP@0.5 **≥ 0.96**（当前最好：队友 0.91548，我们本地 fold0 0.9108）

---

## 一、先把"96 分"翻译成本地指标

按队友的实测换算（同模型本地 0.9265 → 线上 0.894，含 TTA 掉点；去掉 TTA 后差距约 2 点）：

| 线上 | 需要的本地 val（干净口径） |
|---|---|
| 0.9155（队友） | ≈0.935 |
| 0.93 | ≈0.95 |
| **0.96** | **≈0.975 ~ 0.98** |

也就是说：**几乎每个目标都要框对**（4675 个框里错超过 ~100 个就掉到 0.975 以下）。
以现在的数据量（900 张）和模型规模，这是一个**很硬**的目标，但并非不可能：
判据是"同源外部数据 + 更大容量 + 多模型集成"三件事能不能叠加到 +6 点。

**态度**：三轮里每轮都用线上提交校准，如果第 2 轮后线上 <0.94，我会明确说"96 不现实"，
把剩下时间用来把分数做稳（0.94~0.95）+ 写清差距归因——这在报告里同样是加分项。

## 二、三轮排程

### R1 · 13:00–21:30（8.5 h）· 打地基 + 标定

| 步骤 | 内容 | 时长 |
|---|---|---|
| 预训练 | `yolo11l @768` on GWHD-clean 2834 张，40 ep | 2.5~3.0 h |
| 微调 | `yolo11l @1024` on 900 张，140 ep（`close_mosaic=20`） | 5.0~6.0 h |
| 收尾 | test 多尺度推理 → NMS → `submit.zip` | 0.4 h |

**产出**：主力模型 + **线上偏移标定**（本地 OOF 0.93x → 线上实际多少）。这个数决定后两轮怎么打。

### R2 · 21:30–02:00（4.5 h）· 加容量 + 加成员

| 步骤 | 内容 | 时长 |
|---|---|---|
| 主模型 2 | `yolo11x @1024` on 900，120 ep，`--save-period 5`（为 soup 准备） | 3.5 h |
| 折补齐 | fold1~4 `yolo11s@1024` 各 100 ep（可只补 2 折） | 2.1 h/折 |
| 融合 | 3~5 模型 × 896/1024/1280 → NMS / WBF 对比 → **submit #2** | 0.4 h |

**本轮预期**：跨架构集成 + 更大骨干，通常再 +0.5~1.5。

### R3 · 第三天 · 精修（如果线上还差）

| 手段 | 说明 |
|---|---|
| **model soup** | 用 R2 存的 `epoch*.pt` 平均最后 4 个 checkpoint（脚本已就绪） |
| 1280 微调 20 ep | 用 l 模型在 900 张上以 1280 短微调，补分辨率 |
| WBF + soft-NMS | 已在 `predict_ensemble.py` 里实现，扫参数 |
| box_scale | 扫 0.97 / 1.0 / 1.03 对齐 test GT 口径 |
| 5 折全模型集成 | 5 个折模型 + 2 个全量模型 = 7 成员 |

**submit #3** 用当天最优组合。

## 三、提交预算（每天 3 次）

| 时间 | 用途 |
|---|---|
| R1 结束（当晚） | 提交 #1：主力单模型 + 多尺度 → **标定偏移** |
| R2 结束（凌晨/次日） | 提交 #2：跨架构集成 → 验证集成增益 |
| R3 | 提交 #3：soup / box_scale / 1280 里选一个最大增益单变量 |

> 纪律：每次提交前必须先在本地固定口径复算，且一次只改一个变量。绝不空提交。

## 四、为 96 分新加的两个工程件（已完成）

| 工具 | 作用 |
|---|---|
| `scripts/model_soup.py` | 多 checkpoint 权重平均（只对浮点参数平均，整型 buffer 保留），已验证可被 ultralytics 直接加载 |
| `train.py --save-period N` | 每 N 个 epoch 存 `epochN.pt`，给 soup 提供素材 |

## 五、如果 96 到不了，退路是什么

| 情景 | 应对 |
|---|---|
| 线上 <0.93 | 说明预训练/容量这条路走不通，回退"多折集成 + 提交口径调优"，锁定 0.93~0.94 |
| 线上 0.93~0.95 | 继续 R2/R3，主攻集成与 soup，目标 0.95 |
| 线上 ≥0.95 | 用 3 次提交名额做细粒度 A/B（box_scale / NMS IoU / 尺度组合），冲 0.96 |

无论到不到 96，交付物都是完整的：干净可复现的工程 + 同源筛查证据 + 消融表 + 差距归因。
