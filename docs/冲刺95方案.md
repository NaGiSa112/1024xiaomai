## 一、结论先行

1. **队友的 `weights.rar` 没有可用模型**：解压只有 `yolov8n/s/m.pt`，实测 `nc=80`、`epoch=-1`、`date=2022-12-30`、`train_args.data=coco.yaml` → 是 COCO 基座。他训练好的 `m900` 等模型不在包里，所以 **0.91548 暂时无法复现**（要向他要 `submissions/*.zip`，见第六节）。
2. **test 与 val 同分布**（我实测：亮度/饱和/锐度/边缘占比/检出密度几乎一致）→ "线上比本地低 3 个点"更可能来自 **翻转 TTA 掉点 + 100 张 val 选型过拟合 + test GT 口径差异**，而不是域漂移。这决定了"本地 val 涨点"是有效的。
3. **外部数据已经拿到手**：GWHD **3,373 张 1024×1024、147,791 框**，标注格式与赛题完全一致，密度 43.8 框/图（本赛题 42.7）——这是把 0.93 推到 0.95+ 的最大杠杆，**已就绪，随时可训练**。
4. 时间一周+ ⇒ 可以做 **预训练 + 全量 900 微调 + 多模型集成 + 5 折 OOF**，不必赌单次训练。

## 二、两条硬约束下的策略

| 约束 | 影响 | 对策 |
|---|---|---|
| 只能用 test 推理，不能训练 | 不能用伪标签 | 数据增广只来自 GWHD（已获许可） |
| 每天 3 次提交 | 不能靠线上搜索超参 | 本地干净 val 做选型；线上只做"标定 + 验证最大增益项" |

**核心思路：把"容量"和"数据"一起加，而不是继续在 yolov8 同族里集成。**

队友已验证的负结果（直接继承，不再试）：同族集成饱和（+0.0001）、翻转 TTA 有害（-0.005）、简化 WBF 无增益、8 GB 显存是硬墙（我们 24 GB 没有）。

### T1 · 外部数据有效性验证（**最关键的 1 次实验**，~2 h）

```
A: 只用 800 张训练           → 干净 val 基线（yolo11l@1024，100ep，约 1.2 h）
B: GWHD 预训练 → 800 张微调   → 同预算下的增益
```
- 判定：B 比 A 高 **≥1.5 点**才值得走"外部数据"主线；否则说明 GWHD 与本赛题差异大，回到容量路线。
- 显存：yolo11l@1024 bs8 ≈ 12 GB（可与现存任务共存，慢 30~40%）

### T2 · 主力训练（GPU 独占后，~5 h）

| 模型 | 数据 | 配置 | 目的 |
|---|---|---|---|
| yolo11l | GWHD→900 全量 | 1280, bs8, 150ep | 主力 A |
| yolo11x | GWHD→900 全量 | 1280, bs4, 150ep | 主力 B（架构/容量差异） |
| yolo11l | GWHD→900，seed=1 | 1024, bs8, 150ep | 给集成加多样性 |

- 统一：`close_mosaic=15`、`cos_lr`、`cache=ram`、`workers=0`、`scale=0.5`、HSV 0.5
- 每 30 epoch 存一次快照，便于后面做 **model soup**（权重平均，通常 +0.2~0.5）

### T3 · 集成与推理调参（~1.5 h，含自动扫描）

1. `predict_ensemble.py` 扫：`imgsz ∈ {896,1024,1280}`、`nms_iou ∈ {0.5,0.55,0.6,0.65}`、`box_scale ∈ {0.97,1.0,1.03}`、融合方式 `{nms, wbf}`
2. 选型只看干净 val（T1 的 800/100 划分），记录 `_eval.json`
3. 产出 2 个候选提交（一个单模型多尺度、一个跨架构集成）

### T4 · 线上标定与 A/B（提交预算 3/天）

| 提交 | 内容 | 目的 |
|---|---|---|
| #1 | 最强单模型 + 多尺度 + 无 TTA | **标定线上-本地偏移**（关键数字） |
| #2 | #1 的跨架构集成版 | 验证集成增益是否转移到线上 |
| #3 | 按 #1/#2 反馈做单变量微调（如 box_scale 或 imgsz 组合） | 精调 |

- 若 #1 的线上/本地差 ≤1.5 点 → 0.95 主要靠继续涨本地；若差 ≥3 点 → 转"提交口径对齐"路线（box_scale / 置信度分布 / 密度校准）

### T5 · 加码（若 T4 显示还差 1~2 点）

- **5 折 OOF**：900 张切 5 折，每折训一个 yolo11l@1280（~1.5 h/折）→ 得到 900 张的 OOF 指标（噪声 σ 降到 0.002）+ 5 个天然多样模型 → 集成通常 +0.5~0.8
- **多 seed 平均**、**model soup**、**更大分辨率 1536 微调 20 epoch**
